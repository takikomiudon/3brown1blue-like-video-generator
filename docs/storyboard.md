# 最初の長尺動画の構成

会話に残った構成と台本からの復元。旧出力は241.625秒、10場面。
各章の正確な開始時刻は旧タイムラインを回収できていないため、ここに作り足していない。

|順序|題|図の役割|
|---|---|---|
|1|原子から、コンセントまで。|核分裂→熱→蒸気→回転→電気という流れ|
|2|小さな核から、熱が生まれる。|U-235、分裂片と中性子、約200 MeVと質量差|
|3|次の分裂へ、バトンを渡す。|連鎖反応に加えて、漏れと吸収を示す|
|4|増やす？ 減らす？ 保つ？|世代モデル N[g+1]=kN[g] で3つの傾向を比較|
|5|一定に保つ、という技術。|燃料・制御棒・水の役割|
|6|熱→蒸気→回転→電気|加圧水型の二つの回路、タービン、発電機、復水器|
|7|熱のすべてが、電気にはならない。|仮定のエネルギー収支3,000→1,000+2,000 MW|
|8|反応を止めても、冷却は続く。|崩壊熱の定性的な減少と冷却の必要性|
|9|原子力発電を、3つの視点で。|エネルギーの流れ、中性子の収支、停止後の熱|
|10|出典とクレジット|OpenStax、制作参考、HTS Meiの表記|

この長尺動画はPillow+FFmpeg。後の65秒ショートは同じ動画を単に切り出したものではなく、Manimで新規に演出・描画した。
