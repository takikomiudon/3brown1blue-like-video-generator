# 実際に起きた問題と対処

|症状|確認した原因・境界|採用した対処|
|---|---|---|
|チャットの動画リンクを開けない|クラウドの `/workspace/...` パスを渡しており、次の環境にはそのファイルがなかった。|元リポジトリ・ブランチを確認。コードとMP4をGitHubへ保存し、HTTPSから再取得してハッシュを照合。|
|新しい環境のリポジトリがREADMEだけ|復元時のmainは初期コミットだった。2026-10-19に成果をmainへ統合済み。|まず `git branch`、`git log`、`git ls-remote`。リモートのmainを確認する。利用者の変更を保護して更新し、必要なときだけ再生成。|
|`.agents/skills` や調査文書がない|作成・導入しただけで、GitHubへ保存していなかった。|公開元の固定コミットと会話から復元。ファイルハッシュ・ライセンス・索引を作り、別クローンで検証。|
|Docker buildで `.docker/buildx` がread-only|ホストの設定領域に書き込めない。|`BUILDX_CONFIG=/tmp/decay-heat-buildx`。DOCKER_CONFIG、レジストリ認証、HOMEは変更しない。|
|DockerでHTTPSが証明書エラー|内側のコンテナには外側のCAが自動で入るとは限らない。|CAをread-only/BuildKit secretで渡し、該当ツールの信頼設定を使う。TLS・チェックサムを無効化しない。|
|ホストのManimでCairo/Pangoがない|開発ヘッダーが未導入。|実際に検証したManim公式コンテナを使用。|
|日本語が欠ける／豆腐になる|フォントがコンテナから見えない。|Notoをread-onlyマウントし、Pangoが `Noto Sans CJK JP` を見つけることを確認。|
|専門語や章・節が誤読される|PageIndexの音声クエリで「章」がアキラ、「節」がフシ、RAGが英字読みになった。|発音用sayを「しょう」「せつ」「ラグ」に直し、該当音声を再生成。画面の字幕は正しい表記を保持。|
|発音同期のランドマークが見つからない|表示上の「ページ」と、VOICEVOXのモーラ列「ペエジ」が異なった。|生成されたquery.jsonのモーラ列を読み、実際の読みで同期位置を指定する。|
|縮小した原子炉が不透明な四角になる|`set_opacity(.3)` が元は塗りなしの輪郭にも一律の塗りを与えた。|透明度を相対的に落とす `.fade(.65)` を使用。不要な参照図はグラフ前に消す。|
|Manimの最終出力が1フレーム長い|保持時間の丸め。|最後のクレジット保持だけをフレーム契約へそろえる。音声・説明は切らない。|
|音声終了と映像終了が一致しない|末尾の保持に音声がない。|必要な無音をapadで加えて両ストリームの尺を確認。|
|HTS Meiの音声にクリップ|浮動小数PCMがint16の範囲を超え、変換前に切られていた。|変換前に波形を正規化。旧長尺版では最大絶対値26,000へ調整して再生成。|
|コードは成功したが動画が不正|単なるプロセス終了では準備・出力の成功を証明できない。|最終ファイルにffprobeと全編デコード。新しい実行の結果ファイルかも確認。|
|調査先が403|ネットワークの許可範囲やアクセス拒否。|未読と記録する。プロキシを外したり代替経路で制限を回避しない。必要なら正式な設定変更を使う。|
|「バズるテーマ」の根拠が薄い|思いついた疑問を、視聴者が持つ疑問と仮定した。|実際の視聴者・投稿・指標を確認。仮説と実績を区別し、指摘を調査文書に残す。|

## コマンドを再試行するとき

同じ失敗を変更なしで繰り返さない。出力を読み、原因を一つ絞って、意味のある変更後に再試行する。
パイプやログ保存で元コマンドの終了状態を失わない。処理に依存関係があるシェルでは `set -e` 等を使う。
自分が起動したコンテナ・プロセスだけを止める。保存物を消す一般的なpruneやresetで回復しない。
