# 過去の実行記録と現在確認できる成果物

## 最初の長尺動画：会話に残った実行記録

- 241.625秒、1280×720、24fps、5,799フレーム、H.264/yuv420p/AAC。
- 10場面、19字幕キュー、全編デコード成功。
- 出力サイズ8,125,073 bytes。
- HTSの浮動小数PCMをint16へ変換する際、上限に達した67サンプルを検出。変換前に正規化して再生成し、最大絶対値26,000に修正。
- 最終AACのvolumedetectは平均-17.5 dBFS、最大-1.2 dBFS。LUFSの再測定値ではない。
- 各場面の静止画とMP4から抽出した発電系統図を確認。人による全編の聴取評価は未実施。

この旧MP4は現在のGitにない。上記は当時の実行結果を会話から復元した記録であり、今回旧MP4を再取得・再生成して検証したという意味ではない。
