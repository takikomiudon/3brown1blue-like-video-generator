# science-explainer v2.0.0 の制作・検証条件

更新日：2026-10-19。
以前のスキルは、説明対象の動作と確認手順を必須の合格条件として十分に明記していなかった。
題材や映像ツールに依存しない、対象の状態変化と理解の対応を中心に改訂した。

## 完成までに必要な証拠

1. 対象の変化前・途中・変化後と、その変化が説明する関係を計画する。
2. 中心部分を5〜10秒で描画し、実際の中間状態と意味を確認する。
3. 主図に対して、対象の時刻変化・連続性・保持時間を機械的に測定する。
4. 最終MP4の各説明区間を確認し、対象・観察した変化・意味・証拠の時刻をレビューに残す。
5. 最終ファイルのSHA-256とレビューを対応させ、両方の確認が合格してから完成とする。

物理、数学、アルゴリズム、制度などで、動作の種類や対象の構成を変えられる。
検査領域の座標も、その作品の主図から決める。
画素の変化の測定と、その変化が説明を担うかのレビューは別の工程。
どちらも必要な条件として [スキル本体](../.agents/skills/science-explainer/SKILL.md) に明記した。
具体的な書式とコマンドは [動作契約](../.agents/skills/science-explainer/references/motion-contract.md)。

## 検証

こちらで対象の位置・形状・時刻列・補助領域の変化を組み合わせた入力を生成し、14件の回帰検証を実施。
確認待ちの終了コード、意味のレビューの対応範囲、最終ファイルのハッシュも検証した。
さらにスキルのフォルダをコピーし、リポジトリ外の作業ディレクトリで通常のCLIの合格を確認した。
結果と依存ツールの版は [検証記録](animation-contract-v2-validation.json)。

この検証は検査器とパッケージの動作を確認するもので、
別セッションで生成エージェントに新作を制作させる実験は行っていない。
検査値は制作時の初期基準であり、意味や映像の魅力を数値だけで証明するものではない。
これまでに制作した動画に、この新しい検査を実施済みという扱いはしない。
