# 中性子の収支：次回の比較試作の設計案

2026-10-16に作成した設計案を復元。実際の試作動画ではない。
Manim Video Labのdirector packetとsource-backed-patternsに基づく。

- 問い：中性子が複数生まれるのに、なぜ反応を一定にできるのか。
- 残したい理解：生まれた数だけではなく、次の世代につながる割合が重要。
- 型：Simulation Dashboard + Before/After Evidence。
- 順序：粒子 → 数 → 比率 → 式。
- 保存するもの：対象の色、カウンターの位置、グラフの尺度、字幕領域。
- 境界：世代の説明用モデル。実機の時間応答・運転・安全性の計算ではない。

|段階|見せる変化|音声との対応|借りる技法|
|---|---|---|---|
|問い|分裂から複数の中性子が出る|すべて次へ進むのか、という疑問|Composerの問いと段階的提示|
|分岐|漏れ・吸収を暗くし、次へつながる粒子を残す|「吸収」「外へ逃げる」の位置|一つの注目対象、ブックマーク|
|数量化|粒子の集団からカウンターへ対応を作る|次の世代でカウンターが更新|TransformFromCopy、同じ状態から図と数を更新|
|一般化|数の対応を保ったままN[g+1]=kN[g]へ|割合をkと呼ぶ位置|具体像→読取値→記号|
|比較|同じ初期条件で3つの傾向|小さい／一／大きいと曲線を同期|同じ尺度、移動する注目枠|
|着地|k=1の水平線と粒子の収支を残す|結論の後に読む時間|最後の画面を先に設計|
