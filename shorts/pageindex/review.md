## 音声・字幕・形式

- 9区間すべて48kHz / mono / int16、空の波形・int16上限へのクリップがないことを確認。
- 生成クエリのモーラ列を確認。「章＝アキラ」「節＝フシ」を「しょう・せつ」に、RAGを「ラグ」に修正して再生成。
- 重要な探索の進行を、生成された音声クエリの語の時刻へ合わせた。全語の強制アラインメントではない。
- 通常の文字表記へ戻した全文SRTが9区間あり、再生成スクリプトと一致することを確認。
- 二段階のloudnormで調整。最終MP4のサンプルピークは-1.5dBFS。これは実測LUFSの表現ではない。
- 1080×1920 / 30fps / 1937frames / 約64.566秒 / H.264 yuv420p + AAC。
- 720×1280版はH.264 Main level 3.1。両方の最終MP4を全編デコードしてエラーなし。
- 音声の各区間が映像内に収まり、末尾に約2.5秒の保持があることを検証。
