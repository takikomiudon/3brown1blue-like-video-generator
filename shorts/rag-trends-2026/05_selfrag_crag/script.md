# Self-RAG × CRAG

検索結果を、そのまま信じない

基礎論文 2023–2024 / 自己修正

## 1. RAGも、検索に失敗する

画面：取り出した文書は本当に役立つ？

ナレーション：検索したから正しい、とは限りません。検索の失敗をどう扱うか。その考え方を学ぶなら、セルフラグと、コレクティブ・ラグをセットで読むのがおすすめです。

## 2. Self-RAG

画面：検索の要否と、回答を自己評価

ナレーション：セルフラグは、必要に応じて検索し、取り出した文章と生成した回答を評価する仕組みを学習します。原論文では、専用の反省トークンを使います。

## 3. CRAG

画面：検索品質を評価し、取得を補正

ナレーション：シーラグは、検索結果の品質を評価し、必要に応じてウェブ検索などへ切り替える設計です。回答の前に、使う知識の質を立て直します。

## 4. 2つを混同しない

画面：学習した自己評価 / 検索結果の補正

ナレーション：二つの論文は、仕組みが異なります。単にプロンプトで見直しを指示することと、セルフラグの学習方法を再現することは区別しましょう。

## 5. 実装に持ち帰る視点

画面：再検索・停止・追加コストを評価

ナレーション：実務に持ち帰る視点は、どこで失敗を検知し、どう再検索し、いつ止めるかです。正解率だけでなく、余分な検索回数と待ち時間も一緒に比べてください。
