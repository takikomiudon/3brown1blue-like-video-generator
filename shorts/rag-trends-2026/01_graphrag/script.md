# GraphRAG

文書全体の「つながり」を読む

基礎論文 2024 / 実装状況 2026

## 1. その検索、全体が見えてる？

画面：点の検索から、関係の検索へ

ナレーション：グラフラグは、文書全体の傾向を聞くときに読んでおきたい基礎研究です。例えば、千件の議事録に共通する課題は何か。近い文章を数件探すだけでは、全体像を取りこぼします。

## 2. 人・組織・関係を抽出

画面：文書 → 知識グラフ → コミュニティ

ナレーション：論文では、文章から実体と関係を抽出し、知識グラフを構築。つながりの強い集団ごとに要約を作り、それらを使って全体への質問に答えます。

## 3. 向いている問い

画面：「この資料群の主な論点は？」

ナレーション：局所的な事実の検索と、資料群を横断する要約では、必要な検索の設計が違います。まずは、自分の質問がどちらに近いかを見てください。

## 4. 2026年の実装チェック

画面：Microsoft版は保守中心

ナレーション：注意点は、索引作成のコストです。さらに公式実装は、現在、保守中心の方針を明記しています。採用前に、更新方針と必要な機能を確認しましょう。

## 5. まず読む・まず試す

画面：From Local to Global / microsoft/graphrag

ナレーション：読むのは、フロム・ローカル・トゥー・グローバル。少量の文書で、通常の検索と、全体を問う質問を比べるのがおすすめです。出典は付属資料から開けます。
