# 検索 × Rerank

BGE-M3とFlagEmbeddingを押さえる

基礎論文 2024 / 検索の実装

## 1. 型番や略語が見つからない

画面：検索の土台を先に強くする

ナレーション：ラグの改善で、まず確認したいのが検索の土台です。製品の型番や略語を取りこぼすなら、意味の近さだけでなく、語の一致も使う検索を検討しましょう。

## 2. BGE-M3

画面：Dense / Sparse / Multi-vector

ナレーション：基礎論文はエムスリー・エンベディング。ビージーイー・エムスリーは、密なベクトル、疎な表現、複数ベクトルという検索方式を、一つのモデルで扱います。

## 3. 候補を集めて並べ直す

画面：検索 → 候補統合 → Reranker

ナレーション：さらに、集めた候補をリランカーで並べ直す設計があります。質問と候補の組を評価し、最初の検索で上位に来なかった根拠を拾い直す発想です。

## 4. 実装はFlagEmbedding

画面：埋め込みモデルとリランカー

ナレーション：実装を知るなら、フラッグエンベディング。埋め込みモデルとリランカーを確認できます。ビージーイー・エムスリーとリランカーは、別の役割として理解してください。

## 5. 見るべき指標

画面：Recall@k・並べ替え後の品質・遅延

ナレーション：比較は、正しい根拠が候補に入るか、並べ替えで上がるか、待ち時間は増えるか。日本語の型番や固有名詞を含む質問を、検証セットに入れてみましょう。
