# ColPali × Docling

PDFの図表を、検索の対象にする

基礎研究＋実装 / マルチモーダル

## 1. PDFを文字だけにしていませんか

画面：図・表・レイアウトも根拠になる

ナレーション：図や表の多い資料なら、マルチモーダルな検索も押さえましょう。文字だけを取り出すと、グラフの傾向や表の位置関係が落ちることがあります。

## 2. ColPali

画面：ページ画像を複数ベクトルに

ナレーション：コルパリは、文書のページ画像を、視覚言語モデルで複数のベクトルに変換します。質問との細かな対応を使い、必要なページを見つける研究です。

## 3. Docling

画面：文書を構造化して取り込む

ナレーション：取り込み側で知っておきたいのが、ドクリング。文書のレイアウトや表などを扱う変換ツールです。検索を担うコルパリとは、役割が違います。

## 4. 検索と回答を分けて評価

画面：ページを探せても、読めるとは限らない

ナレーション：注意したいのは、正しいページが見つかることと、図表を正しく読めることは別だという点です。ページ検索と、回答生成を分けて検証してください。

## 5. 図表PDFで小さく比較

画面：文字ベース / 画像ベース / 併用

ナレーション：最初の比較は、図表を含む少量のピーディーエフで十分です。文字ベース、画像ベース、その併用を比べ、保存容量や画像処理の費用も測ってみましょう。
