# RAG実装の選び方

LlamaIndex・Haystack・LangGraph

実装ガイド / 2026年10月確認

## 1. ライブラリは、役割から選ぶ

画面：RAGの部品を整理しよう

ナレーション：最後は、ラグを組むときに知っておきたいライブラリです。選ぶ前に、取り込み、検索、処理の制御、評価という役割に分けると、違いが分かりやすくなります。

## 2. LlamaIndex

画面：取り込み・索引・問い合わせ

ナレーション：ラマインデックスは、文書の取り込みや索引、問い合わせの仕組みを組む選択肢。自分のデータと検索をつなぐ部分を調べる、入り口になります。

## 3. Haystack

画面：コンポーネントをパイプラインに

ナレーション：ヘイスタックは、検索器などの部品を、パイプラインとして組み合わせるフレームワークです。各段階の入出力を意識しながら、構成を検討できます。

## 4. LangGraph

画面：状態・分岐・繰り返しの制御

ナレーション：ランググラフは、状態を持つエージェントや処理の制御に注目する選択肢です。再検索の分岐や、途中の状態を扱いたい場合に、公式資料を確認しましょう。

## 5. おすすめの試し方

画面：同じ文書・同じ質問で比較する

ナレーション：役割には重なりがあるので、どれか一つが常に最適とは言えません。同じ資料と質問で小さく作り、根拠の追いやすさ、変更のしやすさ、運用費用で選んでください。
