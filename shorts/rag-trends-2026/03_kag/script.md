# KAG

似ている文章から、条件を満たす知識へ

基礎論文 2024 / OpenSPG

## 1. 「似ている」だけで答えられる？

画面：数値・時点・専門ルール

ナレーション：ケーエージーは、専門分野の知識を使った推論に注目するなら押さえたい研究です。金額の条件や有効期間は、文章の意味が似ているだけでは判定できません。

## 2. 知識と原文をつなぐ

画面：知識グラフ ↔ 原文チャンク

ナレーション：論文では、知識グラフと元の文章を相互に結びつけます。整理した知識を使いながら、その根拠となる原文にも戻れる構造です。

## 3. 推論手順を組み立てる

画面：論理形式に基づくハイブリッド推論

ナレーション：さらに、質問を論理形式で表し、検索や計算などを組み合わせます。複数の事実や条件をたどる、専門的な質問への対応を狙います。

## 4. 導入の山場

画面：スキーマ・知識整備・抽出品質

ナレーション：実装はオープンエスピージーのケーエージー。検討時は、知識のスキーマや抽出品質、運用の手間も見積もりましょう。グラフを作るだけで推論が正しくなるわけではありません。

## 5. 読むべき箇所

画面：知識表現 → 原文との索引 → 推論

ナレーション：まず論文の知識表現と推論の流れを読み、自分の業務ルールを表現できるか確認してください。正解と根拠が分かる質問で、小さく検証するのが出発点です。
