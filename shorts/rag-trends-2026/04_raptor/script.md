# RAPTOR

長い文書を、要約の木で探す

基礎論文 2024 / 階層型検索

## 1. 細切れの検索で文脈が消える

画面：長い文書の理解をどう助ける？

ナレーション：ラプターは、長い文書の細部と全体をつなぐ、階層型検索の基礎論文です。細かく分割した文章だけを検索すると、章をまたぐ意味が見えにくくなります。

## 2. 要約を再帰的に作る

画面：チャンク → 集約・要約 → 上位要約

ナレーション：そこで、文章を埋め込み、似た内容をまとめて要約。さらにその要約をまとめ、抽象度の違う情報を持つ木を、下から作っていきます。

## 3. 必要な粒度から検索

画面：細部の事実と、広い文脈

ナレーション：検索時は、この木の複数の粒度から材料を集めます。詳細な説明と全体的な流れを、一緒に参照できるのがポイントです。

## 4. 要約にも誤りは入る

画面：原文への対応を残す

ナレーション：ただし、要約には省略や誤りが入り得ます。実務では、要約から原文へ戻れる対応を残し、文書の追加時にどの要約を更新するかも設計してください。

## 5. 長文RAGの比較軸に

画面：フラットな検索 vs 階層型検索

ナレーション：読むのは、ラプターの原論文。まず一つの長い資料で、フラットな検索と比較しましょう。細部を問う質問と、複数箇所を統合する質問を分けると違いが見えます。
