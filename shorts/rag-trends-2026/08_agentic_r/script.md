# Agentic-R

検索器も、最終回答から学ぶ

2026年論文 / Agentic Search

## 1. 検索を繰り返すだけでは足りない

画面：Agentic RAGの次の論点

ナレーション：二〇二六年の論文、エージェンティック・アール。注目点は、エージェントだけでなく、検索器も改善することです。似ている文章が、最終回答に役立つとは限りません。

## 2. 局所と全体、両方で学ぶ

画面：質問との関連性 ＋ 最終回答の正しさ

ナレーション：この研究は、各検索での関連性と、最終回答の正しさを使い、文章の有用性を評価します。複数回の検索を前提に、検索器の学習を考え直します。

## 3. エージェントと検索器を改善

画面：検索 → 推論 → 次の検索

ナレーション：エージェントが作る質問が変化するのに合わせ、検索器も反復的に学習します。一回だけの質問と答えで学ぶ検索との違いが、読みどころです。

## 4. 制御の実装ならLangGraph

画面：状態・分岐・再開を管理する

ナレーション：関連する実装ライブラリは、ランググラフ。状態や分岐を持つ処理を組めます。ただし、これを使うだけで、論文の検索器学習が再現できるわけではありません。

## 5. 精度と一緒に測る

画面：検索回数・停止条件・費用

ナレーション：読むときは、最終回答からの評価が検索器へどう届くかに注目を。実装では、検索の回数、停止条件、全体の費用も含めて、効果を比べましょう。
